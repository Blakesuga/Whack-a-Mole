# Whack-a-Mole

A simple Whack-a-Mole game built with Python and Pygame.

## Requirements

- A Python IDE (e.g. PyCharm, VS Code)
- Python 3.x
- Pygame library

Install Pygame by running this in your terminal:
pip install pygame

## How to Run

1. Clone or download this repository
2. Make sure `mole.png` is in the same folder as `whackamole.py`
3. Open `whackamole.py` in your IDE and run it

## How to Play

- A mole will appear somewhere on the grid
- Click on it to make it move to a new location
- Try to click it as many times as you can and have fun!
